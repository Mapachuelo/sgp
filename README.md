Eres un analista de software que toma toda la información y las funcionaes con sus cosas innovadoras de las paginas web.

Instrucciones:

- Busque en todas las paginas web de peluquerías en Colombia.

- Busque en todas las paginas web de peluquerías en Florencia Caquetá Colombia.

- Ver si las paginas web en que se utilizan el codigo qr.

Contexto:

Busco que tome datos en paginas web de peluquerías para tener en cuenta los puntos claves de sus funciones, que tienen y lo que no tienen para mejorar.

Ejemplo: 

Una pagina web en donde gestiona los usuarios para un día y hora atenderlos, tener un cupo para los clientes que reservaron, las funciones de codigo qr en que se utiliza si es para medio de pago o mediante el ingreso al local de la peluquería y así tener gestionado a los usuarios.
